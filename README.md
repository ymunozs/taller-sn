# Taller S y N · Aprender a colaborar

Actividad para practicar los operadores sociolingüísticos de las dimensiones S (compartir recursos e ideas) y N (negociar ideas), a partir del caso ficticio “La tabla de puntos”.

- `index.html`: actividad de estudiantes (se abre con QR).
- `panel.html`: compilación de respuestas para el equipo del taller.
- `datos.js`: generado desde la fuente del caso; no editar a mano.
- `config.js`: URL del recolector (Google Apps Script) y parámetros de la sesión.
